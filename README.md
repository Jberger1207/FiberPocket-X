# FiberPocket X — Standalone Android

Aplicación Android de campo para fibra óptica. Esta build funciona en el celular sin notebook ni servidor.

Incluye Panel, GhostMap, Fault Hunter, Network DNA, Reel Intelligence, Órdenes de Trabajo, Inventario local persistente, registro de capturas y comandos por voz mediante Android.

## Build
El workflow `Build FiberPocket X APK` genera `app-debug.apk` como artifact de GitHub Actions.
